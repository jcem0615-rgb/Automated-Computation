# Required Inputs Checklist

Ask for any of these that are missing before generating a quotation. Group
questions together rather than asking one at a time.

## Contractor Details
- Company Name
- Prepared By (Name & Title)
- Contact Number
- Email
- TIN / Tax ID (optional but preferred for VAT quotations)

## Client Details
- Client Name
- Client Company (if applicable)
- Contact Number
- Email
- Project Site Address

## Quotation Metadata
- Reference Number
- Issue Date
- Validity Period (e.g., "30 days from issue date")

## Materials & Items (Bill of Materials)
For each line item:
- Description
- Quantity
- Unit (pc / m / box / set / etc.)
- Unit Cost (₱)
- Individual Markup % (can be a single blanket markup % for all items if the
  user prefers)

## Labor Breakdown
- Number of Workers
- Daily Rate (₱) — or a Flat Fee if daily rate doesn't apply
- Number of Days (omit if using a Flat Fee)

## Direct Project Fees
- Delivery / Mobilization Fee
- Permits / Local Clearances
- Equipment & Tool Rental
- Any other miscellaneous fees the user wants itemized

## Tax & Payment Terms
- VAT status: Non-VAT or 12% VAT
- Downpayment %
- Progress Billing %
- Payment options (e.g., Bank Transfer, GCash, Check)
- Exclusions (e.g., power tapping fees, structural modifications, out-of-scope work)
